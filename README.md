# Rhythmbox-Folder-Shuffle
This plugin adds an option for Continuous Folder Shuffle to Rhythmbox. 

# Features
- Adds a Shuffle Folders button next to the shuffle button to initiate the folder shuffle playback.
- Folder shuffle can also be started by selecting Tools → Start / Reshuffle Folders.
- Each time folder shuffle is started or restarted, the folder playback order is randomized.
- When pressing the folder shuffle button a second time, the playlist generated by the plugin will be <b>replaced. If you prefer to keep that playlist in addition to the newly created playlist, you must rename the playlist before reshuffling.</b>
- Playback begins at the first track of a randomly selected folder.
- Each folder plays from beginning to end, following the track order, before moving on to another randomly selected folder (regardless of how the tracks are displayed in Rhythmbox's music library).
- Folders are not repeated until all eligible folders have been played, at which point the sequence is reshuffled.
- The plugin respects the currently displayed library filters. For example, if you select a particular genre, only tracks matching that genre are included in the shuffle.
- The currently playing song is automatically highlighted and scrolled into view in the song list, provided it is included in the current filtered view.
- The plugin preserves the current library view and filters while playing.

# Shuffling Methodology
Folder shuffling is intended to be separate and distinct from my related Album Shuffle plugin. While the album shuffle plugin will always start at the beginning of the album and play through the entire album, the folder shuffle will only play one portion of the album if the album is divided into different folders. This can be helpful, for example, with Classical music albums that contain multiple works on the same disc. If each individual work, with all of its tracks, is placed into a separate subfolder, folder shuffle will shuffle by works instead of by albums.

Conversely, if multiple albums are placed in the same folder, those albums will always be played together.

# Installation
Install the foldershuffle folder into either `/usr/lib/rhythmbox/plugins` or `~/.local/share/rhythmbox/plugins`. <p>
For the Flatpak version, install it into `~/.var/app/org.gnome.Rhythmbox3/data/rhythmbox/plugins`. <p>
In Rhythmbox, go to Preferences > Plugins and click "Continuous Folder Shuffle" to activate.

## Please Note
  The plugin is python-based. The issues regarding the breaking of the python-based Rhythmbox plugins was well known, and they were broken in the past for a significant amount of time. Those upstream issues appear to have been rectified now. However, future changes of  Rhythmbox or its dependencies could cause changes that affect this plugin, particularly if those changes break python-loader. Hopefully this will not happen, but if it does, this plugin could break.
